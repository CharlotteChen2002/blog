## Usage

Installation:

```bash
npm install -g pnpm # install pnpm first
pnpm i
```

Development：

```bash
pnpm dev # run server at `localhost:3000`
```

Build：

```bash
pnpm build # compile to `dist` folder
pnpm preview # preview the production build
```
